\# 智能PID恒温混水装置 - Python仿真与可视化平台



\## 环境安装

pip install -r requirements.txt



\## 运行方式

1\. 独立动态动画：

&#x20;  python pid\_animation.py



2\. Web交互式仿真平台：

&#x20;  streamlit run pid\_streamlit\_app.py



\## 文件说明

\- pid\_core.py：PID算法、混水物理模型、性能指标

\- pid\_visualization.py：绘图函数

\- pid\_animation.py：Matplotlib独立动画

\- pid\_streamlit\_app.py：Streamlit Web平台
